# ✨ FestVerse – Interactive Digital Greeting Card Web App

FestVerse is an interactive web application that allows users to create, personalize with their name, and share digital greeting cards for celebrations like Diwali and New Year.

This project focuses on combining creativity with core web development concepts to build a clean, user-friendly, and interactive experience.

---

## 📸 Live Demo
https://fest-verse.vercel.app/ 

## 📌 Overview

FestVerse provides a simple workflow:
- Choose a celebration  
- Customize your greeting by entering your name 
- Preview the card  
- Share it with others  

The app uses URL parameters to dynamically generate personalized greeting cards without requiring a backend.

---

## 🌟 Features

### 🎉 Celebration Pages
- Dedicated pages for:
  - Diwali (Festival of Lights)
  - New Year (Global celebration)
- Each page has its own theme and design

---

### ✍️ Personalization
- Users can add their name to the greeting
- Updates instantly on the page
- Name is stored in the URL for sharing

---

### 🔗 Shareable Greeting Cards
- Generates a unique shareable link
- Supports:
  - Web Share API (mobile)
  - Clipboard copy (desktop fallback)
- Clean card view for recipients (no editing buttons)

---

### 🎨 Interactive UI & Animations
- 🪔 Diwali:
  - Click to light the diya with animation
- 🎆 New Year:
  - Confetti/fireworks animation
- Smooth transitions and responsive design

---

### 🖼️ Card Preview & Export
- Preview greeting before sharing
- Download as PDF using browser print option
- Separate card layout optimized for sharing

---

## 🛠️ Tech Stack

- HTML5 – Structure of the website  
- CSS3 – Styling, layout, and animations  
- JavaScript (Vanilla JS) – Interactivity and logic  

---
## ⚙️ How It Works

1. User selects a celebration  
2. Interacts with the page (e.g., light diya / celebrate)  
3. Adds name (optional)  
4. Clicks "Share" to generate a link  
5. Link contains parameters:
   - theme
   - message
   - sub-message
   - sender name
6. Recipient opens link and sees a clean greeting card
